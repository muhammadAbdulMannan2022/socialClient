# Social Media Project

## Description

This is a social media platform where users can create posts with text and media (images, (videos will come soon) ), like and comment on posts, and interact with each other. The platform is designed to be simple yet powerful, focusing on seamless user experience and media handling.

## Features

- **User Authentication**: Users can sign up, log in, and manage their profiles.
- **Post Creation**: Users can create posts with text, images, videos, and audio.
- **Likes & Comments**: Posts can be liked by users, and users can comment on posts.
- **Responsive Design**: Fully responsive interface to provide a good experience on mobile and desktop.
- **Media Support**: Supports image, video, and audio media in posts.
- **Dynamic Routing**: Posts can be viewed in detail on individual pages.
- **Socket.io Integration**: Real-time communication for updates and interactions.

## Tech Stack

- **Frontend**: React, React Router, Tailwind CSS
- **Backend**: Node.js, Express.js
- **Database**: MongoDB
- **Authentication**: JWT (JSON Web Token)
- **Socket Communication**: Socket.io
- **Cloud Storage**: ImageBB for image media storage
